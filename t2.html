0. 入门：做T到底赚什么钱

做T（也叫“T+0 交易”）不是无风险套利。它的本质是：在你已经持有底仓的前提下， 用同一个标的，利用日内或短线的波动，做一次“低买高卖”或“高卖低买”，赚取差价、或降低持仓成本。

它赚三种钱：①日内波动差价 ②摊薄持仓成本 ③让闲钱多用一次。 但它同样会亏——做反了就是“高买低卖”，成本反而被抬高。

最关键的一条认知：做T做的是纪律和概率，不是预测涨跌。 你不需要猜对方向，只需要在“大概率的位置”做“固定的动作”，长期把小胜累积起来。

小白三条铁律（先背下来）
  1. 不追高、不越跌越买——没有预设规则的钱，一分不投。
  2. T 仓不超过底仓的 1/3——永远给自己留犯错空间。
  3. 先想好“如果错了怎么办”再动手——每笔T都要有放弃/止损条件。

1. 做T基础：正T / 反T / 仓位 / T+0与T+1

1.1 底仓 vs T仓

  • 底仓：你中长期持有的那部分份额，平时不动，是做T的“安全垫”。
  • T仓：专门用来做T的那部分，今天动。做T就是围绕底仓做加减。

1.2 两个方向：正T 与 反T

  • 正T（先买后卖）：在低位先买入T仓，涨上去后卖出等量底仓。 → 适合价格在箱体低位、或日内回调到支撑。需要一笔 T 资金。
  • 反T（先卖后买）：在高位先卖出部分底仓，跌下来再接回。 → 适合价格在箱体高位、或日内冲高。不需要额外资金，但要求你有底仓。
图1 · 正T示意（低吸后高抛）。黑色为价格线、橙色为当日均价线、虚线为昨收。 价格先跌到均价下方（低位），是低吸参考；随后拉回站稳、冲高，是卖旧仓参考。低买 → 高卖，同一数量。
图2 · 反T示意（高抛后低吸）。价格先冲高（高位）→ 先卖底仓；随后回落 → 再接回。 一卖一买，底仓数量不变，成本被摊低。

1.3 T+1 还是 T+0？——这一步决定你能不能做、能做几次

  • A股股票、股票型ETF（宽基/行业/主题）＝ T+1：今天买的份额，明天才能卖。 所以做T只能靠底仓：正T＝先买（今天买、涨了卖昨天的底仓）；反T＝先卖底仓、再买回（买回那部分明天才可卖）。
    → 结论：T+1 标的，一天最多顺着一轮做（不能反复刷）。
  • 黄金ETF、跨境ETF、债券/货币ETF、可转债 ＝ T+0：当日可来回买卖，能真正做“日内多次”。
    → 更灵活，但也更容易手痒、过度交易，必须用规则约束。
务必以券商实际规则为准。不同标的的 T+0 / T+1 可能不同，动手前先确认， 别把“当天买当天卖”当成理所当然。

1.4 仓位与次数

  • T仓 ≤ 底仓的 1/3 ~ 1/2；一次只做一只、一个方向。
  • 单日做T ≤ 1~2 次；做错当天不再补做，防止越做越乱。

2. 看懂分时图（核心）

分时图是“当天”的图：横轴是时间（9:30–15:00，中午 11:30–13:00 休市）， 图上有三样东西——

  • 价格线（通常白色/亮色）：当前成交价。
  • 均价线（黄色）：当天到此刻的成交均价（VWAP），是日内的多空分水岭。
  • 量柱：每个时刻的成交量；基准线是昨收（涨跌的 0 轴）。
图3 · 分时图解剖。看三处：①价格线在均价线上方还是下方 → 强弱；②均价线自身是向上还是向下 → 趋势；③量柱放大还是缩小 → 有没有资金。

2.1 四条核心口诀

  • 价格在均价线上方、且均价线向上 → 强势（做正T相对顺风）。
  • 价格在均价线下方、且均价线向下 → 弱势（别硬做正T；反弹到均价线是减仓参考）。
  • 价格回踩均价线不破 → 支撑（低吸参考）。
  • 价格反弹到均价线被压回 → 压力（高抛参考）。
图4 · 均价线支撑。价格多次回踩橙色均价线都没跌破，随即反弹—— 这是“下沿”的味道，可作为低吸参考，跌破并收在均价线下方则视为支撑失效。
图5 · 均价线压制。价格反弹到均价线附近就被压回——这是“上沿”的味道， 可作为高抛参考。价格站不回均价线上方，说明全天偏弱。

2.2 四个典型形态

图6 · 冲高回落（诱多）。早盘急拉但量跟不上，随后一路走弱、收在均价线下方。 别追高；手上有的，冲高是高抛参考。
图7 · 探底回升（由弱转强）。早盘杀跌到均价线下方后，被拉回并重新站上均价线， 均价线拐头向上——这是低吸参考信号（由弱转强）。
图8 · 单边下跌（弱势）。价格与均价线同步向下，全天没有像样反弹。 别硬做正T；这种日子宁可空着，做也只做反T且仓位小、手要快。
图9 · 量价背离。价格还在涨，但量柱越来越小——上涨缺乏资金支撑，随时可能回落。 见到“价升量缩”，别追、考虑高抛。

2.3 四个关键时点

时段看什么怎么用
09:30–10:00开盘定调，波动最大看高开/低开+首半小时量能，判断今天是强是弱；别急着满仓做。
10:00–11:30主趋势展开价格相对均价线的位置最“诚实”，是主要观察窗。
13:00–13:30午后方向午后第一波常决定尾盘强弱，是重要的低吸/高抛窗口。
14:30–15:00尾盘收尾做T的“收尾”窗口；尾盘强弱也是次日预期的信号。

2.4 常见日内形态图谱（对照学习）

这一节是“看图认形态”。先把 多空 说清，再逐个认 洗盘 / 诱多 / 诱空 / 尾盘拉砸。 每张图下面给你三行：它在干什么（意图）、小白最容易犯的错、正确动作。

2.4.1 先懂“多空 / 多头 / 空头”

  • 多头＝看涨的一方（买单多）；空头＝看跌的一方（卖单多）；多空＝两方的力量对比。
  • 盘面只认两条：价格在均价线上/下，均价线向上/向下。
  • 多头占优：价格在均价线上方、均价线上行、波谷逐步抬高 → 偏正T（低吸顺风）。
  • 空头占优：价格在均价线下方、均价线下行、波峰逐步降低 → 别硬做正T，宁做反T / 观望。
图13 · 多头占优。价格整体在橙色均价线上方，且每一个波谷都比上一个高——买盘不断接住回调，是强势形态。
图14 · 空头占优。价格压在均价线下方，每一个波峰都比上一个低——卖盘一波波压下来，是弱势形态。这种日子别指望“抄底反弹”。

2.4.2 洗盘：缩量阴跌 + 尾盘急拉

图15 · 洗盘（你遇到的那个贯穿形态）。低开 → 拉升（把人吸引进来）→ 缩量缓慢阴跌（钝刀割肉，磨走没耐心的人）→ 尾盘急速拉升（把低位割肉的人甩下车）。
它在干什么阴跌时缩量，说明抛压其实不重——主力用“磨”而不是“砸”来制造恐慌，骗走浮动筹码。
小白易犯的错被缓慢阴跌磨到“感觉快撑不住”，在下跌末段追着卖，正好卖在最低点，然后眼看尾盘拉起。
正确动作① 阴跌途中不卖；要减也在反弹/冲高处挂单。② 看量：缩量阴跌多为洗盘，放量破位才走。③ 把减仓决定推迟到 14:30 后。

2.4.3 诱多：假突破

图16 · 诱多（假突破）。价格冲过“前高 / 箱顶”，吸引追涨盘进场，随后快速回落——追进去的人被套在半山腰。
它在干什么用一次“看起来要突破”的冲高，把追涨的买单骗进来，然后在高位派发。
小白易犯的错看到“突破前高”就追涨买入，结果买在假突破的顶部。
正确动作突破要放量站稳才算数；冲高不放量、随后跌回原位＝假突破，别追，反手可考虑高抛。

2.4.4 诱空：假破位

图17 · 诱空（假破位）。价格跌破“支撑 / 前低”，制造恐慌让人割肉，随后快速拉回原位——割在地板上的人被洗出局。
它在干什么用一次“看起来要崩”的破位，把恐慌盘吓出来，主力在低位捡筹码。
小白易犯的错看到“跌破支撑”就恐慌卖出，正好卖在假破位的坑里（和你说的“卖在最低点”同源）。
正确动作破位后能快速收回、且没放量＝假破位，别慌；真正的破位是放量下杀且收不回来。

2.4.5 尾盘急拉 与 尾盘急砸

图18 · 尾盘急拉。全天平淡甚至偏弱，最后半小时突然放量拉起——常是资金抢筹或做收盘价，次日往往还有惯性。
图19 · 尾盘急砸。全天还行，最后半小时突然跳水——要么是资金离场，要么是躲避隔夜风险，别急着在盘中最低点割，看它收盘能不能收回。
尾盘为什么重要：很多“拉”和“砸”都发生在最后 30 分钟。所以做T尽量不要在盘中最低点做决定，把“要不要动手”留到 14:30 以后再看。

2.4.6 术语速查

多头 / 空头 / 多空看涨方 / 看跌方 / 两方的力量对比。
诱多制造“要涨”的假象（如假突破），骗人追进后回落。
诱空制造“要跌”的假象（如假破位），骗人割肉后拉升。
洗盘（震仓）主力故意打压或磨盘，把没耐心的浮动筹码洗出去。
吸筹 / 出货在低位悄悄买入收集筹码 / 在高位派发卖出筹码。
放量 / 缩量成交量比平时明显放大 / 缩小。“阴跌缩量”多偏洗盘，“破位放量”多偏真走弱。
假突破 / 假破位突破或跌破关键价位后又快速收回，是骗人的动作。

2.5 尾盘定次日：当天怎么收，次日怎么应对

尾盘半小时的价格和量能，是市场对“今天”的总结、对“明天”的投票。 它不能百分百预测次日，但能给你一个概率倾向——真正的作用是让你收盘前就想好“明天怎么办”，而不是开盘了才手忙脚乱。

当天怎么收次日倾向（概率，非必然）应对（做T视角）
尾盘 放量 急拉、收在高点 易高开 / 惯性冲高 冲高别追；若高开滞涨、或放量冲高回落 → 高抛（反T）；回踩不破均价可低吸。
尾盘 无量 拉高、涨幅虚 易“高开低走”（次日不认账） 高开就是送你卖点，优先高抛，别追。
尾盘 放量 急砸、收在低点 易低开 / 惯性下探 低开别急着割，看低开后能否回稳、重新站上均价线。
尾盘 缩量 小跌 / 走平 多为震荡延续 按原方向小额做，不重仓押方向。
全天高开高走、收在最高 易高开延续 连续大涨后防冲高回落，越涨越减、别加仓。
全天低开低走、收在最低 易低开延续（弱势） 反T为主或观望，别硬做正T。
冲高回落后，收在均价线下方 偏弱 次日反抽到均价线，是减仓参考。
探底回升后，收在均价线上方 偏强 次日回踩，是低吸参考。
关键分水岭是“量”：同样是尾盘拉——放量拉多是真的（资金在抢）， 无量拉多是虚的（做收盘价），次日常“高开低走”。尾盘砸也一样：放量砸要防， 缩量砸常是情绪、未必延续。
图20a · 次日“高开高走”（惯性延续）。承接昨天尾盘放量急拉的势头，高开后一路走强。 这种日子的回踩不破均价，是低吸参考。
图20b · 次日“高开低走”（冲高兑现）。同样高开，却冲一下就走弱、跌破均价——昨天拉得虚、或利好兑现。 这种高开是高抛参考，不是买点。

2.5.1 收盘后花两分钟，问三件事（隔夜三问）

  1. 今天怎么收的？——收在均价上还是下？靠近最高还是最低？尾盘放量还是缩量？
  2. 隔夜有没有变量？——外围（隔夜美股、外盘商品/黄金、汇率）、政策/行业消息。黄金、跨境类标的对外围尤其敏感。
  3. 明天可能怎么开，我怎么应对？——高开 → 想减仓 / 不追；低开 → 看能否回稳；平开 → 按结构（位置+均价线）做。
再强调一次：这是“概率倾向”，不是“预测”。A股受隔夜外盘与突发消息影响很大，次日常常被打乱。 所以你要准备的是“应对”，不是“赌方向”——无论怎么开，都有对应的动作，这才是不慌的底气。

3. 多周期怎么看：哪些跟做T强相关

一句话：大周期定方向，小周期找买点。

  • 周K：定大方向 / 结构（在箱体的哪一端、趋势向上还是向下）。决定“要不要做T、做正T还是反T”。
  • 日K：定位置（箱体上下沿、均线支撑压力）。决定“在哪里做”。
  • 60 / 30分钟K：日内节奏（一天里分成几段波段）。
  • 15 / 5分钟K：做T主图——找具体的买点 / 卖点与背离。
  • 1分钟K：精修（手快、超短）。噪音大，小白可以少用。
周期主要用途与做T的相关度
周K定大方向 / 结构中（要不要做、顺不顺势）
日K定位置 / 箱体 / 均线强
60 分钟K日内节奏中
15 分钟K择时 / 背离强
5 分钟K具体买点 / 卖点强
1 分钟K精修 / 超短中
分时（逐笔）日内多空强弱强
顺势原则：上升 / 震荡市，正T更顺； 下跌趋势里以反T为主，而且少做——弱势里硬做正T，最容易“越做越亏”。
图10 · 日K（上）+ 周K（下）对照。周K 告诉你这是“一段大箱体震荡”（大方向）； 日K 告诉你此刻价格落在箱体的低位还是高位（位置）。位置 + 方向，决定你偏正T还是反T。
图11 · 小周期找买点（示意）。在日K给出的“低位”区域里，用 15 分钟K 找具体动作： 回踩均线 + 缩量 + 重新站上，对应分时上“站稳均价线”——这就是一个低吸参考的组合信号。

4. 消息面与大盘 / 板块联动

4.1 消息分四类

  • 宏观 / 政策：利率、财政、监管、汇率 → 影响整个大盘。
  • 行业景气：订单、涨价、补贴、招标 → 影响某个板块 / 指数。
  • 个股公告：业绩预告、增减持、停复牌、重组 → 只影响那只票。
  • 外围：隔夜美股、外盘商品/黄金、汇率 → 影响开盘情绪（黄金、跨境ETF 尤其敏感）。

4.2 联动逻辑：β + 板块 + α

标的价格 ≈ 大盘（β）＋ 板块强弱 ＋ 个股自身（α）。

  • ETF 是一篮子：看它跟踪的指数 / 板块，不要盯单个公司。
  • 大盘强 + 板块强 → 标的顺风，正T 胜率高；反之逆风，优先反T / 观望。
图12 · 大盘与标的的联动（示意）。两条线大多数时间同涨同跌（β）， 但也会阶段性跑赢/跑输（α）。做T时先看大盘“顺不顺风”，再看标的自己强不强。
消息怎么用，关键看“位置”：
  • 高位出利好 → 常是“利好兑现”（见光死）风险，别追。
  • 低位出利空 → 可能是“利空出尽”，别恐慌割在最低。
  • 做T不赌消息，只防消息引发的剧烈波动：一大波放量之后，等价格回稳再动手。

4.3 名字相近的板块会“分化”

像“半导体设备”和“科创半导体设备”这种名字相近的指数， 成分股、编制规则不同，走势会明显不一样。 所以动手前一定先看清：你的标的到底跟踪哪个指数，别“名字像”就当成同一回事。

5. 先把标的分类，再套方法

任何标的，先归到下面三类之一，再套对应动作——这是通用方法能落到你手上任何东西的关键。

类型特点怎么做
T+1 个股
60 / 00 开头股票		 波动大、有α，但只能靠底仓，一天一轮 重质不重量：位置 + 分时都顺才动，一天最多一轮。
T+1 股票 / 行业 / 主题 ETF 看指数/板块，波动通常小于个股 T的差价空间较小，别指望大差价；宁可少做、做确定性高的。

三步自问： ①「它是什么、能不能当天卖？」→ ②「现在在箱体的哪一段位置？」→ ③「今天大盘/板块顺不顺风？」。 三问都过了，才谈“今天怎么动”。

6. 风险与纪律 + 动手前速查清单

6.1 止损与成本

  • 止损：做T做反了，且价格日线收盘跌破箱底、还不收回 → 承认判断失效、降低预期， 不要死扛。
  • 别忘了成本：佣金、卖出股票的印花税、以及买卖价差（滑点）。 做T差价太小（例如不到 1%）时，往往白忙一场。

6.2 纪律

  • T仓 ≤ 底仓 1/3；一次只做一只、一个方向。
  • 不越亏越买、不满仓梭哈、错了就停手。
  • 把每天的目标从“赚多少钱”，改成“规则有没有执行到位”——执行到位，就是赢。 每天赢自己一点点就好。

6.3 动手前速查清单

  1. 它能不能当天卖？（T+0 / T+1）
  2. 我在箱体的高位还是低位？日K / 周K 的方向是什么？
  3. 分时价格在均价线上还是下？量价健康吗？
  4. 今天大盘 / 板块顺不顺风？
  5. 我打算买多少、卖多少？错了在哪止损？
  6. 以上都满足才动手；不满足，今天就不做——“不做”也是一种操作。

术语解释
底仓 / T仓底仓是长期持有的份额（不动）；T仓是今天用来做T的那部分。
正T先低吸买入，涨上去让卖等量旧底仓（先买后卖）。
反T先在高位卖底仓，跌下来再接回（先卖后买），底仓数量不变、成本降低。
分时图当天盘中价格随时间变化的图。
均价线（VWAP）当天到此刻的成交均价，日内多空分水岭。
箱体价格在一个区间内反复震荡：上沿为箱顶、下沿为箱底。
振幅一天中最高价与最低价相对昨收的差距（%），越大越有日内差价。
流动性买卖是否顺畅，常用日均成交额衡量；越大越不容易卡单、滑点小。
支撑 / 压力跌不太下去的价格叫支撑（≈箱底），涨不太上去的叫压力（≈箱顶）。
量价背离价格在涨、量却缩小，上涨缺乏资金支撑。
β / αβ＝随大盘波动的部分；α＝标的自身跑赢/跑输大盘的部分。
T+0 / T+1当天买能否当天卖：能＝T+0；当天买的次日才能卖＝T+1。
滑点想成交的价与实际成交价之间的差，来回一次会有成本。
